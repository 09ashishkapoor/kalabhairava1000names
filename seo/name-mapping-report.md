# Name mapping report

Generated by `node seo/build-name-mapping.mjs` from:

- `sahasranama_meanings.json` — canonical 1,000-entry English dataset.
- `seo/data/legacy-devanagari-names.json` — Devanagari names recovered from the
  pre-English-only commit `b9adb4e` (Hindi UI/prose is not restored; only the
  name spelling field is reused).
- `seo/data/name-overrides.json` — reviewed spelling overrides.

## Current statistics

| Metric | Value |
| --- | --- |
| Name positions | 1,000 |
| Unique pages / slugs | 925 |
| Repeated names (duplicate groups) | 64 |
| Extra positions beyond one page | 75 |
| Rows whose spelling is corroborated by the meaning text | 901 |
| Rows not found verbatim in the meaning text (see note) | 99 |
| Reviewed overrides applied | 71 |

`src/data/name-mapping.json` is the build input for the Astro name pages;
`seo/name-mapping.csv` is the review export.

## Method

1. The Devanagari name for each position is read from the recovered legacy data
   (or an override), transliterated to IAST with the project's
   `devanagariToIast` rules, then rendered into a reader-friendly English
   spelling (anusvara assimilation, `c`/`ch` and `sh` conventions, optional
   `w`/`gy` variants).
2. The site's own uppercase spelling (`english_name`) is kept for search and as
   an "also spelled" variant.
3. Rows where the legacy Devanagari spelling visibly disagrees with the meaning
   text and the site's own spelling are overridden after review, for example
   `Bhirove → Bhirave` (site `BHIIRAVE`) and `Goptri → Goptre` (site `GOPTRE`).
   Overrides are stored in `seo/data/name-overrides.json`; no page is hand-edited.
4. Repeated names are grouped by the site's own spelling so all 75 repeated
   positions share one canonical page. Different spellings for the same name
   that collapse to the same slug get a `-2` suffix.
5. Every row gets variants (dentals, anusvara, `gy`/`w` forms, spaced/unspaced)
   and dative-name stems (`Bhairavaya → Bhairava`) for search and "also spelled"
   blocks.

## What "not found verbatim" means

The 99 flagged rows are mostly names whose *meanings* explain the stem or use a
different inflection (e.g. `Bhūtātmane` explained as `Bhūtātman`), not
necessarily wrong spellings. Flags are a review list, not a correctness claim.
`node seo/build-name-mapping.mjs` prints them on every run.

## Known follow-ups

- Devanagari display for the 71 overridden rows still comes from the recovered
  legacy data. The English spelling, IAST and page slug are corrected; a future
  pass can regenerate Devanagari from the site spelling so the script column
  matches the corrected name.
- Some names in this Sahasranama are dative forms; the "also spelled" stem is a
  search aid, not a separate name.
- Overrides are deliberately conservative. Add a row to
  `seo/data/name-overrides.json` (`{ "42": { "devanagari": "…",
  "spelling_common": "…" } }`) and re-run the mapping script to fix both the
  Devanagari and the English spelling in one place.

## Reproduce

```bash
node seo/build-name-mapping.mjs
node seo/build-data-chunks.mjs  # only if sahasranama_meanings.json changed
npm run build
```
